## 👋 Sobre mí

Soy desarrollador de software en **[Software DSI](https://www.dsinet.com.mx/inicio)**, donde construyo módulos web y reportes que convierten datos en información útil. Fuera de la empresa también tomo proyectos freelance como **DevNick**.

- 🧩 **Módulos web:** frontend con **Ember.js**, backend con **Grails / Groovy**.
- 📊 **Reportes y gráficas:** consultas en **PostgreSQL**, **MySQL** y **SQL**, llevadas a tableros con **Apache ECharts**.
